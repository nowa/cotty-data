# The large data of cotty's experiments

The files of an experiment of cotty that do not fit in its folder, which holds
5 MB at most. Each folder here has the name of the experiment, and the same layout:

    <name>/data/      the output of runs, as the runs left it

The record of the experiment is a page of the documents of cotty, at
https://nowa.im/cotty/research/experiments/<name>/, and links to these files at a
fixed commit. The folder of the experiment in cotty's repository keeps the list of
these files with their SHA-256 sums, as data/external.sha256.
